# Stock Advisor — Plan 2f: News Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the news sources and the news stage (spec §4.2 sources 24–42, §4.3 stage 5). Every run then:
- fetches headlines for the held, watched and shortlisted stocks and coins;
- groups them into stories;
- scores each story with FinBERT;
- stores them in `news_items`;
- adds per-asset news features to the run's `features_live` rows.

**Architecture:**
- **Collectors** (`pipeline/src/advisor/collectors/`), all following the existing `Collector` protocol:
  - `feeds.py` holds the news records and the RSS parser every news source shares.
  - `news_feeds.py` is a table of ten market-wide publishers. Each row becomes one collector, with its own health row.
  - `yahoo_news.py` and `google_news.py` fetch per-stock headlines. Google News is core: it is searched by company name, which the run fills in from the stock directories (`advisor/company_names.py`).
- **The news stage** (`pipeline/src/advisor/news/`):
  - `mapping.py` matches market-wide items to targets by tags, exchange tags, cashtags and names.
  - `stories.py` groups items into stories by link, or by title Jaccard ≥ 0.8 within 48 hours.
  - `sentiment.py` runs FinBERT (optional `nlp` extra).
  - `stage.py` turns items into rows and features.
- **Wiring:** `run.py` runs the stage after enrichment, and `repo.py` stores the rows. Migration `0005` gives each news row a stable story key and an asset type.

**Tests:** the code runs against responses recorded live on 2026-10-15/16, committed with this plan under `pipeline/tests/fixtures/news/`. Every code block and expected value below was run on 2026-10-16 in a scratch worktree, with the full suite passing (551) and ruff clean. The same code fetched all twelve sources live and scored the headlines with FinBERT.

**Tech Stack:** Python 3.12, uv, httpx, pydantic v2, `xml.etree.ElementTree`, `email.utils`, psycopg 3, PyTorch (CPU) and transformers (optional `nlp` extra), pytest, ruff, Docker.

## Plan-level decisions

- **The owner's terms decision (2026-10-16): read terms as a personal feed reader would.**
  - Keep feeds published for personal use, storing headline, link and time only, never article pages, never republished.
  - Drop sources whose terms ban automated access, or that aren't feeds: Seeking Alpha, Investing.com, Financial Post, CoinDesk, Cointelegraph, Reddit, StockTwits, the CNW sitemap.
  - Keep Google News, the spec's core source, even though its feed is licensed "for rendering … within a personal feed reader". The owner accepted that reading.
  - Also dropped, for having no working keyless feed: Benzinga, GlobeNewswire, Business Wire, CNW's RSS.
  - Replacements: WSJ Markets comes from Dow Jones' current feed, and Protos replaces the dropped crypto feeds.
- **Social sources move to a new Plan 2i.** Only ApeWisdom, Google Trends and Wikipedia survive the terms review, and Wikipedia needs a curated ticker → article map. That work is a different shape from news.
- **The twelve news sources:**

| Name | Kind | Publisher | Markets | Notes |
|---|---|---|---|---|

| `yahoo_news` | per stock | Yahoo Finance | US, TSX | undocumented, best-effort |
| `nasdaq_news` | market-wide | Nasdaq (Markets, Stocks, Earnings) | US | names tickers in `<nasdaq:tickers>` |

- **Market-wide feeds are rows in one table, not ten modules.** They differ only in URLs and settings. Each row is still its own collector with its own `source_health` row, and removing a publisher is a one-line change. That keeps the intent of the spec's "one module per source" rule (a source can be swapped without touching the others).
- **A feed that answers 200 isn't necessarily alive.** WSJ's old URL and two MarketWatch feeds are frozen. A feed URL whose newest item is older than its `max_age` counts as failed. Anything that isn't an RSS document, such as a bot check, is an error.
- **Attribution:**
  - A per-stock item counts only for the stock it was fetched for.
  - A market-wide item counts for the targets it names. The evidence, strongest first:
    1. the feed's own tickers (a roundup naming more than 8 counts for none);
    2. exchange tags such as "(NYSE: CNC)" or "(TSX: BBD.B)";
    3. cashtags;
    4. names in the title. The longest name wins, so "Apple Hospitality" isn't Apple. Share classes share a name, and a one-word name that is an everyday word ("Target") needs a tag.
  - Only targets (held, watched and shortlisted assets) are reported.
- **Stories:**
  - Items join a story by shared link, or by title Jaccard ≥ 0.8 within 48 hours. The Jaccard is computed exactly over word sets; MinHash is too noisy on ten-word titles, and exact costs about 2 s (spec §4.3 updated).
  - An item's key hashes its outlet and normalized title. That key is stable across runs, and becomes `news_items.story_key`, unique per asset.
  - Each asset keeps at most 3 stories per outlet, because MarketBeat filled 60 of Google's 100 results for Apple.
- **FinBERT** (`ProsusAI/finbert`, pinned revision, CPU):
  - It is the optional `nlp` extra: CPU PyTorch from the PyTorch index (Linux only, so no CUDA wheels) plus transformers. The scheduled run installs it and tests don't.
  - The model (about 440 MB) is cached by the run workflow.
  - A story's score is P(positive) − P(negative). Labels are read from the model's config, whose order is positive, negative, neutral.
  - With no extra, a failed download, or under 2 minutes of run budget left, stories are stored unscored, and a later run fills the score in.
- **News features**, merged into each target's `features_live` row: `news_stories_48h`, `news_outlets_48h` (coverage breadth), `news_sentiment_mean`, `news_sentiment_trend` (last 24 h minus the 24 h before) and `news_volume_z`. The volume z-score compares the last 24 h's stories with the asset's daily counts over the previous 20 days of stored news, and needs 5 days of history.
- **Storage:**
  - One `news_items` row per (asset, story item). A row a later run sees again keeps its first values and only gains a missing sentiment.
  - Rows older than 90 days are pruned every run (spec §10).
  - Migration `0005` adds `asset_type` (a coin and a stock can share a symbol) and `story_key`.

## Global Constraints

- **No keys:** no data source may need an API key or an account (spec R7, §4.2). Terms are read as a personal feed reader would (owner, 2026-10-16): headline, link and time only, never article pages, never republished.
- **Collector contract (spec §4.1):** `fetch` returns validated records or raises, and never touches the database. SYMBOLS-scope records carry the canonical requested `symbol`. `PartialFetch(records, error)` reports partial failures; an empty one counts as a failure.
- **HTTP and rate limits:** HTTP goes through `get_with_retries`, and loops over requests call `check_deadline()`. Each source gets its `RateLimiter` in the registry.
- **Point in time:** no record may be dated after the run's `as_of` (spec §3, design rule 3). News items are kept only if `published_at <= as_of`.
- **Holdings first:** holdings and the watchlist come first in every collector's symbol list (spec §3 rule 5, §7.2).
- **Tests:** collectors are tested against recorded real responses, with no live network (spec §11). Tests and lint run only in Docker.
- **Tooling:** Python 3.12, ruff with line length 100 and rules E, F, I, UP, B. Migrations are append-only.
- **No real email address** goes in code, tests or docs.

```python
"""News items and the RSS 2.0 parsing every news collector shares (spec §4.2 sources 24–42).

Feeds are read the way a personal feed reader reads them (the owner's terms decision, 2026-10-16):
headline, link and time only, never the article pages.
- **Dates:** every date carries its own offset (GMT, +0000, -0400), and all are converted to UTC.
  An item without a parseable date, title or link is skipped.
- **Errors:** a body that is not an RSS document is an error. That covers a bot check or error page
  sent with HTTP 200.
"""

import html
import re
import xml.etree.ElementTree as ElementTree
from dataclasses import dataclass
from datetime import UTC, datetime
from email.utils import parsedate_to_datetime
from urllib.parse import parse_qsl, urlencode, urlsplit, urlunsplit

from pydantic import BaseModel, ConfigDict, Field

SUMMARY_CHARS = 400
TAG = re.compile(r"<[^>]+>")
SPACE = re.compile(r"\s+")
TRACKER = re.compile(r"utm_\w+|mod|\.tsrc|oc|ref|cmpid|src|time", re.IGNORECASE)


class NewsItem(BaseModel):
    model_config = ConfigDict(frozen=True)

    source: str  # the collector that fetched it
    outlet: str  # the publisher, e.g. "Reuters"
    title: str
    url: str  # without query string or fragment
    published_at: datetime  # UTC
    summary: str = ""  # plain text, at most 400 characters; read only to find tickers
    tags: list[str] = Field(default_factory=list)  # tickers the feed itself names (Nasdaq)


class TickerNewsItem(NewsItem):
    symbol: str  # the stock this item was fetched for


@dataclass(frozen=True)
class FeedEntry:
    title: str
    url: str
    published_at: datetime
    summary: str
    outlet: str | None  # from <source>, which only Google News sends
    tags: list[str]


def plain_text(raw: str | None) -> str:
    """A feed field as text: entities decoded, HTML tags removed, whitespace collapsed."""
    return SPACE.sub(" ", TAG.sub(" ", html.unescape(raw or ""))).strip()


def canonical_url(url: str) -> str:
    """The link without tracking parameters or fragment.

    Trackers such as `?.tsrc=rss` and `?mod=mw_rss_topstories` would otherwise make one story look
    like several. Other parameters stay: MarketWatch bulletins differ only in `?g=`.
    """
    parts = urlsplit(url.strip())
    query = parse_qsl(parts.query, keep_blank_values=True)
    kept = [(key, value) for key, value in query if not TRACKER.fullmatch(key)]
    return urlunsplit(
        (parts.scheme.lower(), parts.netloc.lower(), parts.path, urlencode(kept), "")
    )


def parse_date(text: str | None, *, clock_is_utc: bool = False) -> datetime | None:
    """An RFC 822 date in UTC, or None. A date with no zone ("-0000") is taken as UTC.

    `clock_is_utc` reads the clock time as UTC whatever offset the feed states. BNN Bloomberg
    stamps UTC times with -0400: its newest items would otherwise sit hours after its own
    build time.
    """
    if not text:
        return None
    try:
        moment = parsedate_to_datetime(text.strip())
    except (TypeError, ValueError):
        return None
    if moment.tzinfo is None or clock_is_utc:
        moment = moment.replace(tzinfo=UTC)
    return moment.astimezone(UTC)


def parse_feed(body: bytes, *, clock_is_utc: bool = False) -> list[FeedEntry]:
    """The dated items of an RSS 2.0 document, in the feed's order."""
    try:
        root = ElementTree.fromstring(body)
    except ElementTree.ParseError as exc:
        raise ValueError(f"not an RSS feed: {exc}") from exc
    if root.tag != "rss":
        raise ValueError(f"not an RSS feed: the document is <{root.tag}>")
    entries: list[FeedEntry] = []
    for item in root.iter("item"):
        published = parse_date(item.findtext("pubDate"), clock_is_utc=clock_is_utc)
        title = plain_text(item.findtext("title"))
        link = (item.findtext("link") or "").strip()
        if published is None or not title or not link:
            continue
        tickers = item.findtext("{*}tickers") or ""
        entries.append(FeedEntry(
            title=title,
            url=canonical_url(link),
            published_at=published,
            summary=plain_text(item.findtext("description"))[:SUMMARY_CHARS],
            outlet=plain_text(item.findtext("source")) or None,
            tags=list(dict.fromkeys(t.strip().upper() for t in tickers.split(",") if t.strip())),
        ))
    return entries
```

```python
"""Market-wide news feeds (spec §4.2 sources 27–42): one collector per publisher, all alike.

Each publisher is a row in FEEDS, with:
- its RSS URLs;
- the markets its news is about;
- how old the newest item of each URL may be. A frozen feed still answers 200 (WSJ's old URL, two
  MarketWatch feeds), so a URL whose newest item is older than that counts as failed.

Items are matched to tickers later, in the news stage (`advisor.news`): by the tickers a feed
names, exchange tags such as "(NYSE: CNC)", cashtags and company names. The sources dropped in
Plan 2f (for their terms, a bot wall, or a dead feed) are listed in `docs/superpowers/deferred.md`.
"""

class FeedNews:
    category = Category.NEWS
    core = False
    cadence = Cadence.PER_RUN
    record_type = NewsItem
    freshness = timedelta(days=1)
    scope = Scope.MARKET
    canary: tuple[str, ...] = ()
    canary_requires_records = True
    max_symbols = None

    def __init__(
        self, feed: Feed, client: httpx.Client, limiter: RateLimiter | None = None
    ) -> None:
        self.feed = feed
        self.name = feed.name
        self.best_effort = feed.best_effort
        self.asset_types = feed.asset_types
        self.markets = feed.markets
        self._client = client
        self._limiter = limiter

    def fetch(self, symbols: Sequence[str], as_of: datetime) -> list[NewsItem]:
        start = as_of - LOOKBACK
        records: dict[str, NewsItem] = {}  # by link: a story in two of the publisher's feeds
        failures: list[str] = []
        for url in self.feed.urls:
            try:
                check_deadline()
                response = get_with_retries(self._client, url, limiter=self._limiter)
                entries = [
                    e
                    for e in parse_feed(response.content, clock_is_utc=self.feed.clock_is_utc)
                    if e.published_at <= as_of
                ]
            except DeadlineExceeded:
                if not records:
                    raise
                raise PartialFetch(list(records.values()), BUDGET_EXHAUSTED) from None
            except (httpx.HTTPError, ValueError) as exc:
                failures.append(f"{url}: {type(exc).__name__}: {exc}"[:200])
                continue
            newest = max((e.published_at for e in entries), default=None)
            if newest is None or as_of - newest > self.feed.max_age:
                when = "no items" if newest is None else f"newest item from {newest:%Y-%m-%d}"
                failures.append(f"{url}: {when}, so the feed looks dead")
                continue
            for entry in entries:
                if entry.published_at >= start:
                    records.setdefault(entry.url, NewsItem(
                        source=self.name,
                        outlet=self.feed.outlet,
                        title=entry.title,
                        url=entry.url,
                        published_at=entry.published_at,
                        summary=entry.summary,
                        tags=entry.tags,
                    ))
        items = sorted(records.values(), key=lambda item: item.published_at)
        if failures:
            raise PartialFetch(
                items,
                f"{len(failures)} of {len(self.feed.urls)} {self.feed.outlet} feeds failed;"
                f" first: {failures[0]}",
            )
        return items
```

```python
One request per stock: a request for several symbols returns a merged list that doesn't say which
item belongs to which stock. Links point at the publisher (their `?.tsrc=rss` tracker is dropped).

feed, which is not an error.

from collections.abc import Sequence
from datetime import datetime, timedelta
from urllib.parse import urlsplit

import httpx

from advisor.collectors.base import (
    Cadence,
    Category,
    RateLimiter,
    Scope,
    collect_per_symbol,
    get_with_retries,
)

from advisor.collectors.yfinance_bars import to_yahoo
from advisor.models import AssetType, Market

YAHOO_NEWS_URL = "https://feeds.finance.yahoo.com/rss/2.0/headline"
YAHOO_NEWS_PER_MINUTE = 120
LOOKBACK = timedelta(days=4)


def outlet_of(url: str) -> str:
    """The link's host as an outlet name: `https://www.reuters.com/...` -> `reuters.com`."""
    return urlsplit(url).netloc.lower().removeprefix("www.")


class YahooNews:
    name = "yahoo_news"
    category = Category.NEWS
    core = False
    best_effort = True
    cadence = Cadence.PER_RUN
    asset_types = frozenset({AssetType.STOCK})
    markets = frozenset({Market.US, Market.TSX})
    record_type = TickerNewsItem
    freshness = timedelta(days=1)
    scope = Scope.SYMBOLS
    canary = ("AAPL",)
    canary_requires_records = True
    max_symbols = None

    def __init__(self, client: httpx.Client, limiter: RateLimiter | None = None) -> None:
        self._client = client
        self._limiter = limiter

    def fetch(self, symbols: Sequence[str], as_of: datetime) -> list[TickerNewsItem]:
        start = as_of - LOOKBACK

        def one(symbol: str) -> list[TickerNewsItem]:
            response = get_with_retries(
                self._client,
                YAHOO_NEWS_URL,
                params={"s": to_yahoo(symbol), "region": "US", "lang": "en-US"},
                limiter=self._limiter,
            )
            return [
                TickerNewsItem(
                    symbol=symbol,
                    source=self.name,
                    outlet=outlet_of(entry.url),
                    title=entry.title,
                    url=entry.url,
                    published_at=entry.published_at,
                    summary=entry.summary,
                )
                for entry in parse_feed(response.content)
                if start <= entry.published_at <= as_of
            ]

        return collect_per_symbol(symbols, one)
```

```python
"""Company names for news: the phrase Google News is searched for, and the name headlines use.

Names come from the stock directories the run loads before enrichment:
- NASDAQ Trader, e.g. "Apple Inc. - Common Stock";
- TMX, e.g. "Royal Bank of Canada".

A stock with no known name (an OTC holding, or the daily health check, which loads no directory) is
searched by ticker.
"""

import re
import threading
from collections.abc import Mapping

# What follows the company in a directory name: NASDAQ's " - Common Stock", and NYSE's
# " Class B Common Stock", " Common Units representing ...", " American Depositary Shares".
INSTRUMENT = re.compile(
    r"\s+(?:-\s+.*|(?:Class\s+[A-Z]\s+)?"
    r"(?:Common|Ordinary|Subordinate Voting|American Depositary|Depositary)\b.*)$"
)
LEGAL = re.compile(
    r"(?:,?\s+&?\s*(?:Inc|Incorporated|Corp|Corporation|Co|Company|Ltd|Limited|plc|PLC|LLC"
    r"|L\.P|LP|N\.V|S\.A|SA|SE|AG|Holdings?|Group)\.?)+$"
)


def search_name(directory_name: str) -> str:
    """'Apple Inc. - Common Stock' -> 'Apple Inc'. TMX names, such as 'Royal Bank of Canada', are unchanged."""
    return INSTRUMENT.sub("", directory_name).strip().rstrip(".").strip()


def short_name(directory_name: str) -> str:
    """The name headlines use: 'United Airlines Holdings, Inc. - Common Stock' -> 'United Airlines'."""
    return LEGAL.sub("", search_name(directory_name)).strip(" ,.&").removeprefix("The ")


class CompanyNames:
    """Directory names by symbol. The run fills them once the universes are loaded."""

    def __init__(self, names: Mapping[str, str] | None = None) -> None:
        self._names = dict(names or {})
        self._lock = threading.Lock()

    def update(self, names: Mapping[str, str]) -> None:
        with self._lock:
            self._names.update(names)

    def get(self, symbol: str) -> str | None:
        with self._lock:
            return self._names.get(symbol)

    def items(self) -> list[tuple[str, str]]:
        with self._lock:
            return list(self._names.items())
```

```python
"""Per-stock headlines from Google News search RSS (spec source 25; core).

It is the one source that finds TSX companies by name.

**Queries.** One query per stock, for the company's directory name in quotes over the last 2 days:
`"Apple Inc" when:2d`. TSX stocks are searched in Canada's edition. A stock without a known name is
searched as `<ticker> stock`.

**Results.** A query returns at most 100 items, newest first.
- Titles end in " - <outlet>". That suffix is dropped, and the outlet comes from `<source>`.
- Links are opaque Google tokens that differ by query, so the news stage tells stories apart by
  outlet and title.

**Terms.** The feed is licensed for a personal feed reader. The owner chose to keep it on that basis
(2026-10-16): one query per stock per run, headlines only.

**Blocking.** Google answers a bot check with an HTML page or a 429. Either one stops the source
for the run.
"""

from collections.abc import Sequence
from datetime import datetime, timedelta

import httpx

from advisor.collectors.base import (
    Cadence,
    Category,
    RateLimiter,
    Scope,
    collect_per_symbol,
    get_with_retries,
)
from advisor.collectors.feeds import TickerNewsItem, parse_feed
from advisor.company_names import CompanyNames, search_name
from advisor.markets import TSX_SUFFIX, market_of
from advisor.models import AssetType, Market

GOOGLE_NEWS_URL = "https://news.google.com/rss/search"
GOOGLE_NEWS_PER_MINUTE = 60
LOOKBACK = timedelta(days=2)
EDITIONS = {
    Market.US: {"hl": "en-US", "gl": "US", "ceid": "US:en"},
    Market.TSX: {"hl": "en-CA", "gl": "CA", "ceid": "CA:en"},
}


class GoogleBlocked(Exception):
    """Google News answered with a bot check instead of a feed."""


def blocked(exc: Exception) -> bool:
    """A bot check or a 429: stop asking Google News for the rest of the run."""
    if isinstance(exc, GoogleBlocked):
        return True
    return isinstance(exc, httpx.HTTPStatusError) and exc.response.status_code == 429


def query_for(symbol: str, name: str | None) -> str:
    if name:
        return f'"{search_name(name)}" when:2d'
    return f"{symbol.removesuffix(TSX_SUFFIX)} stock when:2d"


def headline(title: str, outlet: str | None) -> str:
    """'Apple sues Masimo - Reuters' -> 'Apple sues Masimo' when Reuters is the outlet."""
    suffix = f" - {outlet}"
    return title.removesuffix(suffix) if outlet and title.endswith(suffix) else title


class GoogleNews:
    name = "google_news"
    category = Category.NEWS
    core = True
    best_effort = False
    cadence = Cadence.PER_RUN
    asset_types = frozenset({AssetType.STOCK})
    markets = frozenset({Market.US, Market.TSX})
    record_type = TickerNewsItem
    freshness = timedelta(days=1)
    scope = Scope.SYMBOLS
    canary = ("AAPL", "RY.TO")
    canary_requires_records = True
    max_symbols = None

    def __init__(
        self,
        client: httpx.Client,
        limiter: RateLimiter | None = None,
        *,
        names: CompanyNames | None = None,
    ) -> None:
        self._client = client
        self._limiter = limiter
        self._names = names if names is not None else CompanyNames()

    def fetch(self, symbols: Sequence[str], as_of: datetime) -> list[TickerNewsItem]:
        start = as_of - LOOKBACK

        def one(symbol: str) -> list[TickerNewsItem]:
            response = get_with_retries(
                self._client,
                GOOGLE_NEWS_URL,
                params={
                    "q": query_for(symbol, self._names.get(symbol)),
                    **EDITIONS[market_of(symbol)],
                },
                limiter=self._limiter,
            )
            try:
                entries = parse_feed(response.content)
            except ValueError as exc:
                raise GoogleBlocked(f"Google News sent no feed (a bot check?): {exc}") from exc
            return [
                TickerNewsItem(
                    symbol=symbol,
                    source=self.name,
                    outlet=entry.outlet or "Google News",
                    title=headline(entry.title, entry.outlet),
                    url=entry.url,
                    published_at=entry.published_at,
                )
                for entry in entries
                if start <= entry.published_at <= as_of
            ]

        return collect_per_symbol(symbols, one, is_fatal=blocked)
```

```python
"""Which stocks and coins a market-wide news item is about (spec §4.3 stage 5).

Evidence, strongest first:
1. the tickers a feed names (Nasdaq's `<nasdaq:tickers>`). A roundup naming more than 8 counts for
   none of them.
2. exchange tags in the title or summary: "(NYSE: CNC)", "NASDAQ:AAPL", "(TSX: BBD.B)". TSX
   Venture and CSE tickers are outside the universe.
3. cashtags: "$AAPL", "$BTC".
4. names in the title. Every stock in both universes contributes its short name ("Apple",
   "Royal Bank of Canada") and each held or watched coin its name ("Bitcoin"). The longest name
   wins where names overlap, so a headline about Apple Hospitality is not read as Apple. Share
   classes share a name, so "Alphabet" counts for both GOOG and GOOGL. A one-word name that is also
   an everyday word ("Target", "Gap") counts only through tags or cashtags.

from collections.abc import Iterable, Mapping

COMMON_WORDS = frozenset({

    "Travelers", "Trust", "Union", "United", "Unity", "Universal", "Value", "Visa", "Western",
})


def tsx_symbol(ticker: str) -> str:
    """'BBD.B' as written in a press release -> 'BBD-B.TO', the form the app uses."""
    return ticker.replace(".", "-") + TSX_SUFFIX


def words(text: str) -> list[str]:
    """The words of a title, with possessives dropped ("Apple's" -> "Apple")."""
    return [word.removesuffix("'s").removesuffix("’s") for word in WORD.findall(text)]


class TickerMap:
    def __init__(
        self,
        stock_names: Mapping[str, str],  # every stock of both universes: symbol -> directory name
        coin_names: Mapping[str, str],  # held and watched coins: symbol -> name
        targets: Iterable[AssetRef],
    ) -> None:
        self._targets = frozenset(targets)
        self._names: dict[tuple[str, ...], set[AssetRef]] = defaultdict(set)
        for symbol, directory_name in stock_names.items():
            self._add(short_name(directory_name), AssetRef(symbol, AssetType.STOCK))
        for symbol, name in coin_names.items():
            self._add(name, AssetRef(symbol, AssetType.CRYPTO))

    def _add(self, name: str, ref: AssetRef) -> None:
        key = tuple(words(name))
        if key and len(key) <= LONGEST_NAME and not (len(key) == 1 and key[0] in COMMON_WORDS):
            self._names[key].add(ref)

    def assets_in(self, item: NewsItem) -> set[AssetRef]:
        """The targets an item names, by any of the four kinds of evidence."""
        found: set[AssetRef] = set()
        if len(item.tags) <= MAX_TAGS:
            found |= {AssetRef(tag, AssetType.STOCK) for tag in item.tags}
        text = f"{item.title} {item.summary}"
        for exchange, ticker in EXCHANGE_TAG.findall(text):
            if exchange in US_EXCHANGES:
                found.add(AssetRef(ticker, AssetType.STOCK))
            elif exchange == "TSX":
                found.add(AssetRef(tsx_symbol(ticker), AssetType.STOCK))
        for ticker in CASHTAG.findall(text):
            found |= {AssetRef(ticker, AssetType.STOCK), AssetRef(ticker, AssetType.CRYPTO)}
        found |= self._named(item.title)
        return found & self._targets

    def _named(self, title: str) -> set[AssetRef]:
        """Names in the title, longest first at each position, scanning left to right."""
        tokens = words(title)
        found: set[AssetRef] = set()
        start = 0
        while start < len(tokens):
            for size in range(min(LONGEST_NAME, len(tokens) - start), 0, -1):
                refs = self._names.get(tuple(tokens[start:start + size]))
                if refs:
                    found |= refs
                    start += size
                    break
            else:
                start += 1
        return found
```

```python
"""Stories: one per news event, however many feeds and queries carried it (spec §4.3 stage 5).

**Grouping.** Two items are one story when they share a link, or when their titles' word sets have a
Jaccard similarity of at least 0.8 within 48 hours.

**Why exact Jaccard.** It replaces the spec's MinHash estimate. At a few thousand headlines exact
Jaccard costs about two seconds, while MinHash on ten-word titles is too noisy at 0.8 (Plan 2f
research).

**Keys.**
- An item's key is a hash of its outlet and normalized title. Google's links differ by query, so a
  link can't be the key, and the key is stable from run to run.
- A story's id is the key of its earliest item.
"""

import hashlib
import re
from collections import defaultdict
from collections.abc import Sequence
from datetime import timedelta

from advisor.collectors.feeds import NewsItem

SIMILAR = 0.8
WINDOW = timedelta(hours=48)
TOKEN = re.compile(r"[a-z0-9$%.]+")


def title_words(title: str) -> frozenset[str]:
    return frozenset(TOKEN.findall(title.lower()))


def story_key(item: NewsItem) -> str:
    """Stable across runs: the outlet and the title's words, lower-cased."""
    normalized = " ".join(re.findall(r"[a-z0-9]+", item.title.lower()))
    return hashlib.sha1(f"{item.outlet.casefold()}|{normalized}".encode()).hexdigest()[:16]


def similar(a: frozenset[str], b: frozenset[str]) -> bool:
    if not a or not b or min(len(a), len(b)) < SIMILAR * max(len(a), len(b)):
        return False  # sizes alone rule out a Jaccard of 0.8
    return len(a & b) >= SIMILAR * len(a | b)


def cluster(items: Sequence[NewsItem]) -> dict[str, str]:
    """Story id by item key, oldest items first; each item joins the first story it matches."""
    ids: dict[str, str] = {}
    by_url: dict[str, str] = {}
    stories: list[tuple[frozenset[str], NewsItem, str]] = []  # (words, first item, story id)
    index: dict[str, list[int]] = defaultdict(list)  # word -> stories whose first title has it
    for item in sorted(items, key=lambda i: (i.published_at, story_key(i))):
        key = story_key(item)
        if key in ids:
            continue
        found = by_url.get(item.url)
        if found is None:
            item_words = title_words(item.title)
            candidates = sorted({n for word in item_words for n in index[word]})
            for n in candidates:
                first_words, first, story_id = stories[n]
                if item.published_at - first.published_at <= WINDOW and similar(
                    item_words, first_words
                ):
                    found = story_id
                    break
            if found is None:
                found = key
                for word in item_words:
                    index[word].append(len(stories))
                stories.append((item_words, item, key))
        ids[key] = found
        by_url.setdefault(item.url, found)
    return ids
```

```python
"""Headline sentiment with FinBERT (spec §4.3 stage 5): ProsusAI/finbert on the CPU.

**Model.** About 440 MB, pinned to a revision, and downloaded once into the Hugging Face cache, which
the run workflow keeps between runs. Its licence (CC BY-NC-SA 4.0) allows this personal,
non-commercial use.

**Dependencies.** torch (CPU build) and transformers are the optional `nlp` extra. The scheduled run
installs them and tests don't. Without them, stories get no sentiment rather than failing the run.

**Score.** A story's score is P(positive) minus P(negative), in [-1, 1]. The model's labels are read
from its config, because they come in the order positive, negative, neutral.
"""

from collections.abc import Callable, Sequence

FINBERT = "ProsusAI/finbert"
FINBERT_REVISION = "0bc2ac10dda6929bcb1f77ccc43c7ec5c424f031"
BATCH = 32
MAX_TOKENS = 64

Scorer = Callable[[Sequence[str]], list[float]]


def load_finbert() -> Scorer | None:
    """A FinBERT scorer, or None when the `nlp` extra isn't installed."""
    try:
        import torch
        from transformers import AutoModelForSequenceClassification, AutoTokenizer
    except ImportError:
        return None
    tokenizer = AutoTokenizer.from_pretrained(FINBERT, revision=FINBERT_REVISION)
    model = AutoModelForSequenceClassification.from_pretrained(
        FINBERT, revision=FINBERT_REVISION, use_safetensors=True
    )
    model.eval()
    label = {name.lower(): index for index, name in model.config.id2label.items()}
    positive, negative = label["positive"], label["negative"]

    def score(titles: Sequence[str]) -> list[float]:
        scores: list[float] = []
        with torch.inference_mode():
            for start in range(0, len(titles), BATCH):
                batch = tokenizer(
                    list(titles[start:start + BATCH]),
                    padding=True,
                    truncation=True,
                    max_length=MAX_TOKENS,
                    return_tensors="pt",
                )
                probabilities = model(**batch).logits.softmax(dim=-1)
                scores.extend((probabilities[:, positive] - probabilities[:, negative]).tolist())
        return scores

    return score
```

```python
"""The news stage (spec §4.3 stage 5): from fetched headlines to stories, sentiment and features.

1. Keep the items published in the 48 hours before `as_of`.
2. Attribute each item. A per-stock item (Google News, Yahoo) goes to its stock. A market-wide item
   goes to the targets it names (`advisor.news.mapping`).
3. Group items into stories (`advisor.news.stories`). Each asset keeps one item per story, and at
   most 3 stories per outlet: MarketBeat alone filled 60 of Google's 100 results for Apple.
4. Score each story's headline once (FinBERT).
5. Compute per-asset features: stories, outlets, mean sentiment, and the sentiment trend (the last
   24 h minus the 24 h before). The volume z-score compares the last 24 h's stories with the
   asset's daily story counts in news_items before them.
"""

import statistics
from collections import defaultdict
from collections.abc import Mapping, Sequence
from dataclasses import dataclass
from datetime import datetime, timedelta

from advisor.collectors.feeds import NewsItem, TickerNewsItem
from advisor.models import AssetRef, AssetType
from advisor.news.mapping import TickerMap
from advisor.news.sentiment import Scorer
from advisor.news.stories import cluster, story_key

WINDOW = timedelta(hours=48)
RECENT = timedelta(hours=24)
OUTLET_CAP = 3
MIN_HISTORY_DAYS = 5


@dataclass(frozen=True)
class NewsRow:
    ref: AssetRef
    published_at: datetime
    outlet: str
    url: str
    title: str
    sentiment: float | None
    cluster_id: str
    story_key: str


@dataclass(frozen=True)
class NewsOutcome:
    rows: list[NewsRow]
    features: list[tuple[AssetRef, dict]]
    summary: dict


def attribute(items: Sequence[NewsItem], ticker_map: TickerMap) -> list[tuple[AssetRef, NewsItem]]:
    pairs: list[tuple[AssetRef, NewsItem]] = []
    for item in items:
        if isinstance(item, TickerNewsItem):
            pairs.append((AssetRef(item.symbol, AssetType.STOCK), item))
        else:
            pairs.extend((ref, item) for ref in sorted(ticker_map.assets_in(item)))
    return pairs


def _mean(values: Sequence[float]) -> float | None:
    return statistics.fmean(values) if values else None


def volume_z(recent: int, history: Sequence[int]) -> float | None:
    """How unusual the last 24 h's story count is against the daily counts before it."""
    if len(history) < MIN_HISTORY_DAYS:
        return None
    spread = statistics.pstdev(history)
    return (recent - statistics.fmean(history)) / spread if spread > 0 else None


def process_news(
    items: Sequence[NewsItem],
    ticker_map: TickerMap,
    targets: Sequence[AssetRef],
    as_of: datetime,
    *,
    scorer: Scorer | None,
    history: Mapping[AssetRef, Sequence[int]],
) -> NewsOutcome:
    recent = [item for item in items if as_of - WINDOW <= item.published_at <= as_of]
    story_of = cluster(recent)

    chosen: dict[AssetRef, dict[str, NewsItem]] = defaultdict(dict)  # asset -> story -> item
    for ref, item in sorted(attribute(recent, ticker_map), key=lambda p: p[1].published_at):
        chosen[ref].setdefault(story_of[story_key(item)], item)  # the story's earliest item
    kept: dict[AssetRef, list[tuple[str, NewsItem]]] = {}
    for ref, stories in chosen.items():
        per_outlet: dict[str, int] = defaultdict(int)
        kept[ref] = []
        for story, item in sorted(stories.items(), key=lambda s: s[1].published_at, reverse=True):
            if per_outlet[item.outlet] < OUTLET_CAP:
                per_outlet[item.outlet] += 1
                kept[ref].append((story, item))

    headlines: dict[str, str] = {}
    for stories in kept.values():
        for story, item in stories:
            headlines.setdefault(story, item.title)
    scores: dict[str, float] = {}
    if scorer is not None and headlines:
        ordered = sorted(headlines)
        scores = dict(zip(ordered, scorer([headlines[s] for s in ordered]), strict=True))

    rows = sorted(
        (
            NewsRow(
                ref=ref,
                published_at=item.published_at,
                outlet=item.outlet,
                url=item.url,
                title=item.title,
                sentiment=scores.get(story),
                cluster_id=story,
                story_key=story_key(item),
            )
            for ref, stories in kept.items()
            for story, item in stories
        ),
        key=lambda row: (row.ref, row.published_at),
    )

    features: list[tuple[AssetRef, dict]] = []
    for ref in targets:
        stories = kept.get(ref, [])
        newer = [scores[s] for s, i in stories if s in scores and as_of - i.published_at <= RECENT]
        older = [scores[s] for s, i in stories if s in scores and as_of - i.published_at > RECENT]
        both = newer + older
        last_day = sum(1 for _, item in stories if as_of - item.published_at <= RECENT)
        features.append((ref, {
            "news_stories_48h": len(stories),
            "news_outlets_48h": len({item.outlet for _, item in stories}),
            "news_sentiment_mean": _mean(both),
            "news_sentiment_trend": (
                _mean(newer) - _mean(older) if newer and older else None
            ),
            "news_volume_z": volume_z(last_day, history.get(ref, [])),
        }))

    return NewsOutcome(
        rows=rows,
        features=features,
        summary={
            "items": len(recent),
            "stories": len(set(story_of.values())),
            "rows": len(rows),
            "assets": len([ref for ref in targets if kept.get(ref)]),
            "sentiment": "finbert" if scorer is not None else "unavailable",
        },
    )
```

```python
def merge_features_live(
    conn: psycopg.Connection,
    run_id: int,
    rows: Sequence[tuple[AssetRef, dict]],
    as_of: datetime,
) -> None:
    """Add features to each asset's row for this run, creating the row if there is none yet."""
    if not rows:
        return
    with conn.cursor() as cur:
        cur.executemany(
            "insert into features_live (run_id, symbol, asset_type, features, as_of)"
            " values (%s, %s, %s, %s, %s)"
            " on conflict (run_id, symbol, asset_type)"
            " do update set features = features_live.features || excluded.features",
            [(run_id, ref.symbol, ref.asset_type.value, Jsonb(feats), as_of) for ref, feats in rows],
        )


def write_news_items(conn: psycopg.Connection, rows: Sequence[NewsRow]) -> None:
    """Store news rows. A row an earlier run stored is kept; it only gains a missing sentiment."""
    if not rows:
        return
    with conn.cursor() as cur:
        cur.executemany(
            "insert into news_items (symbol, asset_type, published_at, outlet, url, title,"
            " sentiment, cluster_id, story_key) values (%s, %s, %s, %s, %s, %s, %s, %s, %s)"
            " on conflict (symbol, asset_type, story_key)"
            " do update set sentiment = coalesce(news_items.sentiment, excluded.sentiment)",
            [
                (
                    row.ref.symbol, row.ref.asset_type.value, row.published_at, row.outlet,
                    row.url, row.title, row.sentiment, row.cluster_id, row.story_key,
                )
                for row in rows
            ],
        )


def prune_news_items(conn: psycopg.Connection, now: datetime, kept: timedelta = NEWS_KEPT) -> int:
    """Delete news published more than 90 days before `now`; returns how many rows went."""
    return conn.execute("delete from news_items where published_at < %s", (now - kept,)).rowcount


def news_daily_counts(
    conn: psycopg.Connection, refs: Iterable[AssetRef], since: datetime, until: datetime
) -> dict[AssetRef, list[int]]:
    """Each asset's stories per UTC day in [since, until), over the days that have any news.

    A day with news for other assets but none for this one counts as 0; a day with no news at all
    (before the pipeline started) is left out.
    """
    rows = conn.execute(
        "select symbol, asset_type, (published_at at time zone 'UTC')::date as day,"
        " count(distinct cluster_id) as stories from news_items"
        " where published_at >= %s and published_at < %s group by 1, 2, 3",
        (since, until),
    ).fetchall()
    days = sorted({row["day"] for row in rows})
    counts: dict[AssetRef, dict[date, int]] = defaultdict(dict)
    for row in rows:
        counts[AssetRef(row["symbol"], AssetType(row["asset_type"]))][row["day"]] = row["stories"]
    return {ref: [counts[ref].get(day, 0) for day in days] for ref in refs}
```

```python
def empty_news_summary() -> dict:
    return {"items": 0, "stories": 0, "rows": 0, "assets": 0, "sentiment": "not run"}


def news_stage(
    deps: RunDeps,
    run_id: int,
    results: Mapping[str, CollectorResult],
    targets: EnrichTargets,
    coin_names: Mapping[str, str],
    now_utc: datetime,
    deadline_at: float,
) -> dict:
    """Stage 5: store the run's stories and merge per-asset news features into features_live."""
    sources = {n for n, c in deps.collectors.items() if c.category is Category.NEWS}
    repo.prune_news_items(deps.conn, now_utc)
    if not sources:
        return empty_news_summary()
    items = [record for name in sources if name in results for record in results[name].records]
    refs = [AssetRef(s, AssetType.STOCK) for s in targets.stocks]
    refs += [AssetRef(s, AssetType.CRYPTO) for s in targets.crypto]
    ticker_map = TickerMap(dict(deps.names.items()), coin_names, refs)
    history = repo.news_daily_counts(
        deps.conn, refs, now_utc - RECENT - NEWS_HISTORY, now_utc - RECENT
    )
    scorer: Scorer | None = None
    if not items:
        sentiment = "no items"
    elif time.monotonic() > deadline_at - SCORING_RESERVE_SECONDS:
        sentiment = "skipped: run budget"
    else:
        try:
            scorer = deps.news_scorer()
        except Exception as exc:  # a failed model download must not fail the run
            sentiment = f"failed: {type(exc).__name__}: {exc}"[:200]
        else:
            sentiment = "finbert" if scorer is not None else "unavailable"
    outcome = process_news(items, ticker_map, refs, now_utc, scorer=scorer, history=history)
    repo.write_news_items(deps.conn, outcome.rows)
    repo.merge_features_live(deps.conn, run_id, outcome.features, now_utc)
    return {**outcome.summary, "sentiment": sentiment}
```
