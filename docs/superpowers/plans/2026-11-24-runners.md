# Runners Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A separate Runners list: each morning, US stocks at $0.50–$5 that had a huge-volume up day yesterday, each with a swing-trade plan, SEC warnings, a paper track record and a weekly backtest that picks one frozen rule.

**Architecture:** A new `pipeline/src/advisor/runners/` package holds one rule implementation used by both the live stage and the backtest. The pre-open run calls the live stage on the daily bars it already downloads for the whole US universe; tracking is recomputed from bars each morning, so nothing drifts after a split. The weekly training workflow runs the backtest on the build's `prices_US.parquet` and freezes rule version 1. The web reads three new tables on a new `/runners` page.

**Tech Stack:** Python 3 (numpy, pandas, psycopg, pytest), Postgres/Supabase migration with RLS, Next.js + Vitest + Playwright.

**Spec:** `docs/superpowers/specs/2026-11-24-runners-design.md` (approved by the owner 2026-11-24). Read it first; where this plan and the spec disagree, the spec wins.

## Global Constraints

- Free, keyless data only: Yahoo daily bars already in the run, SEC EDGAR through the existing `SecEdgar` client.
- No look-ahead: a signal uses only bars dated on or before the signal day D; the entry is D+1's open.
- US stocks only, long only. Runners never appear in Picks, Invest or the holdings advice; none of those files change.
- The runners stage never fails or degrades a run: every failure is caught and recorded in `summary["runners_error"]`.
- All SQL lives in `pipeline/src/advisor/store/repo.py`.
- Spec numbers, verbatim: price band **$0.50–$5.00**; volume **10×** the 50 sessions before D (alternatives 5×, 20×); close up **20%** (15%, 30%); close in the top **50%** of D's range (top 25%, none); D's dollar volume at least **US$2M**; first ignition in **20** sessions; **50** sessions of history; no gap rule (alternatives 15%, 25%); stop = the higher of D's low and **25%** under the entry (alternatives: D's low alone; 35% under); target **2R** (1.5R, 3R); hold **10** sessions with the entry day as day 1 (5, 20); spread floor **1.0%**, cap **10%**; gate: newest-third average net R above 0 over at least **100** signals **and** at least **40** closed live signals over at least **2 months** with average net R above 0; choose a variant only with at least **200** signals; max loss default **C$50**.
- Work on branch `runners`. Run `git commit` as its own command. Never `--no-verify`. Do not push.
- Local commands: pipeline tests with `pipeline/.venv/Scripts/python.exe -m pytest` (integration tests need `TEST_DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:54322/advisor_test`); web Vitest and Playwright from PowerShell in `web/`; apply the migration locally with `web\node_modules\.bin\supabase.cmd migration up --local` from the repo root.
- Known local limit: `test_schema.py` tests that switch to the `pipeline_rw` role fail locally with `permission denied to set role` (10 already do on main). A new test failing only at that step is expected locally; CI decides.

## Review Focus

1. **The stock opens below the signal day's low** (a gap down at the entry): the stop must still be under the entry. Expected: the 25% floor alone is used; with no floor set, the signal is `skipped` with reason "opened under the stop". (Task 3)
2. **No bars after the signal** (halted or delisted): a waiting signal with no bar 5 sessions after D becomes `skipped` ("no prices after the signal"); an open runner with no bar 5 sessions past its hold-by date closes as `held` at its last close. (Task 5)
3. **A bar dated today in the morning's data** (a forced or late run): the stage must ignore bars dated on or after the run's New York date, for signals and for tracking. (Task 5)
4. **Zero or missing volume in the 50-session window:** an average volume of 0 gives no signal and no division by zero. (Task 2)
5. **SEC is down or the stock has no CIK:** the signal is still stored, with `warnings_checked = false`, and the card says "Filings not checked". (Tasks 4, 5, 9)

```python
    min_change: float = 0.20
    min_close_pos: float | None = 0.50      # None = no close-position test
    min_dollar_volume: float = 2_000_000.0

@dataclass(frozen=True)
class Series:
    days: Sequence[date]
    open: np.ndarray; high: np.ndarray; low: np.ndarray; close: np.ndarray; volume: np.ndarray
    raw_close: np.ndarray                   # the price as it traded that day; equals close in the live run

def series_of(bars: Sequence[DailyBar]) -> Series       # sorted by day; raw_close = close

@dataclass(frozen=True)
class Ignitions:
    signal: np.ndarray          # bool per session
    split_suspect: np.ndarray   # bool per session: met the rule but skipped as a suspected unrecorded split

def stats_at(s: Series, i: int, rule: Rule) -> dict[str, float]   # change_pct, volume_x, dollar_volume, close_pos
```

**The rule, exactly.** For session `i`, with `avg = mean(volume[i-history_sessions:i])`:

- `candidate[i]` = `i >= history_sessions` and `avg > 0` and `volume[i] >= volume_x * avg` and `close[i] / close[i-1] - 1 >= min_change` and close position `>= min_close_pos` (position = `(close - low) / (high - low)`; `1.0` when `high == low`; skipped when `min_close_pos is None`) and `close[i] * volume[i] >= min_dollar_volume` and `price_min <= raw_close[i] <= price_max`.
- `suspect[i]` = `candidate[i]` and some session `t` in `[i - history_sessions, i - 1]` has `open[t] / close[t-1] >= 2.0` **and** `volume[t] < mean(volume[max(0, t-50):t])` (a reverse split shrinks the share count; a real spike multiplies volume).
- `signal[i]` = `candidate[i]` and not `suspect[i]` and no `candidate` in `[i - quiet_sessions, i - 1]`.

**Interfaces — Consumes:** `Bar`, `Rule`, `Series`, `STARTING` (Task 2). **Produces:**

```python
@dataclass(frozen=True)
class Plan:
    entry: float; stop: float; target: float; hold_by: date
    @property
    def r(self) -> float: ...           # entry - stop

def plan_for(entry: float, signal_low: float, hold_by: date, rule: Rule) -> Plan | None

def gapped(signal_close: float, entry: float, rule: Rule) -> bool

@dataclass(frozen=True)
class Outcome:
    status: Literal["open", "target", "stop", "held"]
    exit_day: date | None; exit_price: float | None; gross_r: float | None
    last_day: date; last_close: float

def settle(bars: Sequence[Bar], plan: Plan) -> Outcome      # bars start on the entry day; never empty

# cost.py
FLOOR, CAP = 1.0, 10.0

def two_day_spread(h1: float, l1: float, h2: float, l2: float) -> float   # percent, never negative

def spread_pct(s: Series, i: int) -> float

def cost_r(spread: float, entry: float, stop: float) -> float            # spread * entry / (entry - stop) / 100
```

**Decisions the tests don't fully pin:**

- `plan_for`: the stop is the highest of the available candidates, floored to the cent: `signal_low` when it is below `entry`, and `entry * (1 - stop_floor)` when `stop_floor` is set. Floor with `math.floor(x * 100 + 1e-9) / 100` (1.92 × 0.75 must give 1.44, not 1.43). `None` when no candidate is available or the stop is not above 0. Target = `round(entry + target_r * (entry - stop), 2)`.
- `settle`, each bar in order: open at or under the stop → `stop` at the open; open at or above the target → `target` at the open; low at or under the stop → `stop` at the stop (a bar touching both is a stop); high at or above the target → `target` at the target; `bar.day >= hold_by` → `held` at the close. Otherwise carry on; after the last bar, `open`.
- `two_day_spread` is Corwin–Schultz: `β = ln(h1/l1)² + ln(h2/l2)²`, `γ = ln(max(h1,h2)/min(l1,l2))²`, `k = 3 − 2√2`, `α = (√(2β) − √β)/k − √(γ/k)`, spread = `max(0, 2(e^α − 1)/(1 + e^α)) × 100`.
- `spread_pct(s, i)`: the **median** of `two_day_spread` over the consecutive-day pairs inside the 20 sessions before `i` (fewer when history is shorter; `FLOOR` when there is no pair), clamped to `[FLOOR, CAP]`. *(Plan's call inside the spec's "builder's call": the spec's D and D−1 pair gives 0 on AKAN's own ignition day, because one huge range swamps the estimate; the quiet sessions before D measure the spread.)*

| Kind | Trigger | Text |
| --- | --- | --- |
| `share_sale` | form in F-1, S-1, F-3, S-3 or their `/A`, filed in the last 90 days | `Filed a {form} on {date}: a share sale may be pending.` |
| `share_sale` | form starting `424B`, filed in the last 30 days (wins over a registration) | `Filed a {form} prospectus on {date}: shares are being sold.` |
| `reverse_split` | Yahoo split ratio below 1 in the last 90 days | `Reverse split 1-for-{round(1/ratio)} on {date}.` |
| `reverse_split` | else an 8-K with item 5.03 in the last 90 days | `Filed an 8-K (item 5.03) on {date}: a charter change, often a reverse split.` |
| `reverse_split` | else one of the 3 most recent 6-Ks in the last 90 days whose document matches | `A 6-K on {date} mentions a reverse split.` |
| `deficiency` | an 8-K with item 3.01 in the last 12 months (365 days) | `Filed an 8-K (item 3.01) on {date}: an exchange listing notice.` |

```python
def runners_stage(
    conn: psycopg.Connection,
    bars: Mapping[str, Sequence[DailyBar]],
    universe: Sequence[SymbolInfo],            # the run's US universe: funds, warrants, units, preferreds already out
    now_utc: datetime,
    *,
    sec: SecEdgar | None = None,
    splits: Callable[[Sequence[str]], Mapping[str, list[tuple[date, float]]]] | None = None,
) -> dict[str, int]   # {"signals", "split_suspect", "entered", "closed", "open", "unchecked"}
```

In `registry.py`: `make_sec(settings: Settings, client: httpx.Client) -> SecEdgar` (the construction now inline in `build_registry`), and `build_registry(..., sec: SecEdgar | None = None)` uses the one passed. In `run.py`: `RunDeps.sec: SecEdgar | None = None`; `main` builds one `SecEdgar` with `make_sec` and passes it to both.

**What the stage does**, with `today` = the run's New York date and `D` = `previous_sessions(today - 1 day, 1)[0]`:

1. **Cut look-ahead:** every symbol's bars are trimmed to days `<= D` before anything else. *(Review Focus 3.)* The bars are Yahoo's adjusted ones, so a split Yahoo has recorded is already applied to the whole window, and the latest bar is the price as traded.
2. **Rule:** `repo.live_runner_rule(conn)`; None means version 0 with `STARTING`.
3. **New signals:** for each universe symbol whose last bar is dated `D`: `ignitions(series, rule)`; a signal at the last index is stored with `stats_at`, `spread_pct`, a preview plan `plan_for(signal_close, signal_low, sessions_after(US, D, rule.hold_sessions), rule)` (stop, target, hold_by, `cost_r`), the name from the universe, and `warnings_for` (splits fetched once for all the day's signal symbols through `splits`; without it, no splits). A split-suspect at the last index is only counted.
4. **Track** every unsettled signal, by its own `rule_version` (`repo.runner_rule_settings`; 0 → `STARTING`), recomputing from the trimmed bars each time:
   - bars after `signal_day` empty: if `D` is 5 or more sessions after `signal_day` → `skipped`, reason "no prices after the signal"; else leave waiting.
   - entry = the first such bar's open; `gapped(...)` → `skipped`, "gapped up at the open"; `plan_for(...)` None → `skipped`, "opened under the stop".
   - otherwise `settle(bars from the entry day, plan)`; store entry_day, entry, stop, target, cost_r, last_day, last_close and, when settled, exit_day, exit_price, gross_r, `net_r = gross_r - cost_r`, status.
   - an `open` runner whose last bar is 5 or more sessions before `D` and whose `hold_by + 5 sessions <= D` → `held` at its last close, reason "no prices: closed at the last close". *(Review Focus 2.)*
5. **Prune:** `repo.prune_runner_signals(conn, today - 730 days)`.

**In `execute_run`:** only when `kind is RunKind.PRE_OPEN` and `universe_ok`, after the phase-2 `bars` merge:

### Task 6: The backtest

**Files:**

- Create: `pipeline/src/advisor/runners/backtest.py`
- Test: `pipeline/tests/unit/test_runners_backtest.py`

**Interfaces — Consumes:** Tasks 2–3. **Produces:**

```python
MIN_TO_CHOOSE = 200

def load_series(prices: pd.DataFrame, events: pd.DataFrame) -> dict[str, Series]

def sessions_of(prices: pd.DataFrame) -> list[date]                      # every day any symbol traded, ascending

def trades(series: Mapping[str, Series], sessions: Sequence[date], rule: Rule) -> pd.DataFrame

def variants(base: Rule) -> list[tuple[str, Rule]]

def report(rows: pd.DataFrame) -> dict

def cutoff_of(sessions: Sequence[date]) -> date                          # the first session of the newest third

def run_backtest(series: Mapping[str, Series], sessions: Sequence[date], frozen: Rule | None) -> dict
```

**Decisions:**

- `load_series`: `prices` has the training build's columns `symbol, day, open, high, low, close, volume` (adjusted); `events` has `symbol, day, dividend, split`. `raw_close[t] = close[t] × Π(split ratios of that symbol's events dated after day t)`, ignoring zero ratios and dividends (dollar volume needs no rebuilding: adjusted close × adjusted volume is the same product). Keep only symbols whose `raw_close` was ever inside `[0.50, 5.00]`.
- `trades`: one row per signal with columns `symbol, signal_day, entry_day, status, skip_reason, gross_r, cost_r, net_r` and `split_suspect` rows excluded but counted in `rows.attrs["split_suspect"]`. Hold-by = `sessions[index(entry_day) + rule.hold_sessions - 1]`. A signal with no bar after D, or whose hold-by is past the end of `sessions`, is dropped (incomplete). Statuses as live: `skipped` (gap or "opened under the stop"), `target`, `stop`, `held`; a trade still `open` at the data's end is dropped.
- `variants(base)`: the base as `"starting values"`, then one setting changed at a time: `volume_x` 5, 20; `min_change` 0.15, 0.30; `min_close_pos` 0.75, None; `gap_skip` 0.15, 0.25; `stop_floor` None, 0.35; `target_r` 1.5, 3.0; `hold_sessions` 5, 20 — **15 in all**, named like `"volume 20x"`.
- `report(rows)`: `{"signals": trades not skipped, "skipped_gap": n, "skipped_other": n, "target": n, "stop": n, "held": n, "avg_net_r", "median_net_r", "lost_over_1r": share of trades with gross_r < -1, "worst": the 10 lowest net_r as [{symbol, signal_day, net_r}]}`; averages are None with no trades. Skipped rows are not trades.
- `run_backtest`: `older` = rows with `signal_day < cutoff_of(sessions)`, `newer` = the rest. Among variants with at least `MIN_TO_CHOOSE` older trades, the pick is the highest older `avg_net_r` (ties: the earlier in `variants`); with none, the pick is the base and `note = "too few signals to choose"`. Returns `{"data_from", "data_to", "cutoff", "variants_tried": 15, "pick": {"name", "settings", "older", "newer", "note"}, "frozen": {"settings", "older", "newer"} | None, "split_suspect": n}`; `frozen` reports the rule passed in. Every date in the result is an ISO string, so the dict stores as JSON unchanged.
